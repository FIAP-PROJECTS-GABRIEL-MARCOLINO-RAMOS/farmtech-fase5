# Scripts

- `executar_notebook.py`: executa o notebook do início em um kernel novo, usando o
  mesmo Python do ambiente; valida e salva o relatório somente após execução bem-sucedida.
- `gerar_grafico_aws.py`: calcula subtotais com Decimal, exporta a tabela e gera o gráfico.

Executar a partir da raiz, com as dependências instaladas no ambiente virtual.
